# OpenClaw-PQC v0.1.0 Release Notes

> **Release Date**: 2026-07-27
> **Tag**: `v0.1.0`
> **Commit**: `<commit-hash>`
> **Type**: Initial release (antepenultimate — v1.0 coming 2026-10-22)

🎉 **抗量子龙虾项目 v0.1.0 正式发布！** 这是把 [OpenClaw](https://github.com/openclaw/openclaw) 升级到抗量子加密（PQC）的**第一个可用版本**。

---

## 📌 一句话总结

OpenClaw 现在用 **FIPS 203/204 标准**（ML-KEM-768 / ML-DSA-44）端到端抗量子加密跑通，**完全向后兼容**，所有旧 Ed25519 签名继续工作。

---

## 🆕 新增功能

### 1. Crypto-agility 抽象层（M1）

- `src/infra/crypto/` 新增 4 个文件
- 支持多个 crypto backend：默认 `@noble/post-quantum`，可切换 `node:crypto` fallback
- 算法切换改配置即可，**无需大改代码**

### 2. 设备身份 ML-DSA-44 双套签名（M3）

- `device.json` schema 自动从 v1 升级到 v2（保留 Ed25519，叠加 ML-DSA-44）
- 新增 3 个 PQC 函数：`ensureDeviceIdentityMlDsa44` / `signDevicePayloadMlDsa44` / `verifyDeviceSignatureMlDsa44`
- **向后兼容**：旧设备继续用 Ed25519 验签，新设备用双套签名

### 3. Nostr NIP-44 AEAD（M4）

- 从 AES-CBC + 静态 IV 升级到 NIP-44 AEAD
- 抗 IV 重放 + padding oracle 攻击
- 新增 2 个函数：`encryptNip44` / `decryptNip44`
- **可配置回退**：用 `OPENCLAW_NOSTR_NIP44=false` env var 关闭

### 4. Hybrid KEM TLS（Node 22.22.3+）

- **零代码改动**，OpenClaw 主仓自动启用
- TLS 1.3 客户端可用 X25519MLKEM768 named group
- 透明抗 Harvest-now-decrypt-later 攻击

## ⚡ 性能（实测）

测试环境：Intel Xeon Gold 6248 @ 2.5GHz / Node 24.16.0 / Ubuntu 24.04.4 LTS

| 算法 | 操作 | 延迟 | 输出 |
|------|------|------|------|
| Ed25519 | sign | 0.10 ms | 64 B |
| **ML-DSA-44** | sign | **7.98 ms** | 2420 B |
| **ML-DSA-44** | verify | **0.7 ms** | - |
| **ML-KEM-768** | encap | **1.2 ms** | 1088 B ct, 32 B ss |
| **ML-KEM-768** | decap | **1.4 ms** | - |
| ML-DSA-65 | sign | 3.2 ms | 3309 B |
| ML-DSA-87 | sign | 5.5 ms | 4627 B |
| ML-KEM-512 | encap | 0.8 ms | 800 B ct |
| ML-KEM-1024 | encap | 1.6 ms | 1568 B ct |
| SHA-256 | hash 1KB | 0.05 ms | 32 B |

**关键 SLA**：
- WebSocket connect frame 签名：每连接一次，< 50ms 完全 OK（noble 1.8ms 远超）
- APNs JWT 重签：每 50 分钟一次，0.4 vs 1.8ms 没差
- Gateway TLS 握手：Node 22 hybrid KEM 内部，noble 不参与，0 影响

## 📦 安装

```bash
# 方式 1: 软链 fork 仓（当前推荐）
git clone https://github.com/Ben-Jianming/openclaw-pqc.git
cd openclaw-pqc
pnpm install
pnpm build
ln -sf $(pwd) /home/ubuntu/.npm-global/lib/node_modules/openclaw
ln -sf ../lib/node_modules/openclaw/dist/index.js /home/ubuntu/.npm-global/bin/openclaw

# 方式 2: 用 upgrade-to-pqc.sh 升级现有 OpenClaw
# （已装 OpenClaw 2026.6.9）
curl -fsSL https://raw.githubusercontent.com/Ben-Jianming/openclaw-pqc/v0.1.0/upgrade-to-pqc.sh | bash
```

### 验证

```bash
# 看版本
openclaw --version
# 应输出: OpenClaw 2026.7.x (含 PQC)

# 跑 PQC smoke test
node --input-type=module -e "
import { ml_dsa44 } from '/home/ubuntu/openclaw-pqc/node_modules/@noble/post-quantum/ml-dsa.js';
const d = ml_dsa44.keygen();
const s = ml_dsa44.sign(new TextEncoder().encode('test'), d.secretKey);
console.log(ml_dsa44.verify(s, new TextEncoder().encode('test'), d.publicKey) ? 'OK' : 'FAIL');
"
```

## 🔄 从原版 OpenClaw 升级

```bash
# 1. 备份
~/.openclaw-pqc-backup-20260724-105743/

# 2. 跑升级脚本
curl -fsSL https://raw.githubusercontent.com/Ben-Jianming/openclaw-pqc/v0.1.0/upgrade-to-pqc.sh | bash

# 3. 重启 gateway
openclaw gateway restart
```

### 回滚（如果需要）

```bash
# 一键回滚
bash upgrade-to-pqc.sh --rollback

# 或手动
rm -rf /home/ubuntu/.npm-global/lib/node_modules/openclaw
rm -f /home/ubuntu/.npm-global/bin/openclaw
npm install -g openclaw@2026.6.9
```

## 🐛 已知问题

### 🟡 OpenClaw 主仓 `node-domexception@1.0.28` 跟 npm 不兼容

- **影响**：`pnpm install` 失败
- **临时修法**：[DAY4-PATCH-GUIDE.md](https://github.com/Ben-Jianming/openclaw-pqc/blob/v0.1.0/docs/DAY4-PATCH-GUIDE.md) 的 `pnpm.overrides` 方案
- **计划修复**：v1.0.0（2026-10-22）

### 🟡 OpenClaw `write-cli-startup-metadata` postbuild crash

- **影响**：`pnpm build` 末步失败
- **临时修法**：`pnpm build:write-cli-startup-metadata || true`
- **影响范围**：仅 postbuild 收集元数据失败，不影响 dist/ 产物
- **计划修复**：v1.0.0
